# Casa Familias 5.0

- CasaFamilias-5.0-pruebas.apk: aplicación nativa optimizada para Android8 o posterior. Instálala como actualización y usa internet.
- CasaFamilias-5.0-proyecto.zip: código de Android Studio, migraciones y documentación, sin cachés ni claves de firma.
- CasaFamilias-5.0-disenos.zip: nueve propuestas visuales individuales y capturas del emulador claramente separadas. Los datos de las imágenes son ficticios.
- VERIFICACION.md: resultados ejecutados y límites.
- PRUEBAS-EN-TU-CELULAR.md: comprobaciones con las cuentas y el teléfono reales.
- SHA256SUMS.txt: integridad de los archivos.

Actualiza tu carpeta de la computadora desde GitHub Desktop: Fetch origin → Pull origin. Abre CasaFamiliasAndroid, no el ZIP histórico de la raíz. Esta entrega es para presentar/probar; no se publicó en Google Play.
