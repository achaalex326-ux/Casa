Promedio automático según facturas

El sistema calcula el promedio con las últimas seis facturas históricas sin exceso del restaurante. No tienes que escribir el promedio a mano.

Promedio de aguaSin historial
Promedio de luzSin historial
Registra facturas anteriores marcando “factura histórica” para crear la base. Desde la segunda factura normal, el cálculo se actualiza automáticamente.

Notificaciones por correo y celular

Cuando una familia sube el comprobante de un pago mensual, todos reciben un aviso dentro de la app. Si cada usuario activa los avisos en su celular, también verá una notificación del sistema mientras la PWA está activa. El correo se envía mediante la función notify-payment-upload.

Correo: requiere configurar RESEND_API_KEY y NOTIFY_FROM_EMAIL en Supabase Edge Functions.
Celular: cada usuario debe pulsar “Activar avisos en este celular”. En teléfonos requiere que la app esté publicada por HTTPS.
